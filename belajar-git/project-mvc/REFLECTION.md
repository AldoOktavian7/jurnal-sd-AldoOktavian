# REFLECTION

## Refleksi Pembelajaran Minggu 1–7

Selama mengikuti praktikum dari Minggu 1 hingga Minggu 7, saya mempelajari penggunaan Git dan GitHub, workflow kolaborasi tim, branching, merging, GitHub Projects, serta konsep arsitektur MVC.

Materi yang paling sulit saya kuasai adalah branching dan merging pada Git. Pada awalnya saya sering mengalami kebingungan ketika berpindah branch, melakukan merge, dan menyelesaikan conflict yang muncul saat penggabungan kode.

Untuk mengatasi hal tersebut, saya mencoba lebih sering berlatih menggunakan Git melalui terminal dan GitHub. Saya juga mempelajari kembali fungsi dari perintah-perintah penting seperti git branch, git checkout, git merge, git pull, dan git push agar lebih memahami alur kerja kolaborasi dalam tim.

Selain itu, saya juga mengalami kesulitan dalam memahami konsep MVC karena harus membedakan fungsi Model, View, dan Controller. Namun setelah mencoba membuat struktur project secara langsung, saya mulai memahami bahwa MVC membantu membuat kode lebih terstruktur, rapi, dan mudah dikembangkan.

Dari praktikum ini saya belajar bahwa Git dan GitHub bukan hanya digunakan untuk menyimpan source code, tetapi juga sangat penting dalam mendukung kerja sama tim, manajemen project, serta dokumentasi pengembangan aplikasi secara profesional.
